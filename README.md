# Birthday Microsite

Personalized birthday microsite with an interactive greeting, message sections, a photo gallery and a song section. Built with HTML, CSS and JavaScript.

A small personal web experience focused on presentation, interaction and mobile-friendly browsing.

## Included

- A greeting and reveal/continue flow.
- Expandable message and story sections.
- A photo gallery with navigation.
- A dedicated song section.

## Stack and preview

HTML, CSS and JavaScript. Open `index.html` in a browser or serve the project folder with a static web server.

Media behavior depends on the assets supplied with the project. This repository is a personal microsite, not a reusable hosted service.
